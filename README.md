# CodeAlpha Internship Task 1 - CGPA Calculator

## Description
A simple CGPA Calculator developed using C++.

## Features
- Takes number of courses as input
- Takes course name, grade point and credit hours
- Calculates total credits
- Calculates total grade points
- Calculates final CGPA
- Displays the result clearly

## Technology Used
- C++

## Sample Output
Final CGPA: 8.09
